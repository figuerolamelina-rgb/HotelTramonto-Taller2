# Referencias SQL originales de Iara

Estos diez archivos se conservan byte a byte desde `feature/iara` (`11440cf6`).
No constituyen el instalador de la versión integrada. No ejecutarlos en bloque ni
sobre las correcciones ya migradas: incluyen escritores anteriores sin GUID,
firmas alternativas de confirmación y una fecha de consumo que rellenaría datos
históricos con la fecha de instalación.

La versión integrada conserva las escrituras coordinadas de 01/04, el incremento
de ciclo 07/08 y las consultas/fecha nullable de 09/10. Ninguno se ejecuta
automáticamente. Ver `docs/integracion-final-iara-melina.md` para el orden y los
límites de aceptación. Los hashes de las referencias originales están en
`docs/inventario-integracion-iara-melina.json`.
